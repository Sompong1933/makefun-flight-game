Sky Courier — a complete flight game that plays offline in a desktop browser from its own files. Fly a bush plane over a green island: thread glowing rings, land on two runways, mind your fuel and your speed. Three missions (Ring Run, Island Hop, Free Flight), a chase view and a lit cockpit view, a software 3D island with mountains, a lake, clouds and two airfields, and synthesized engine sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Controls

- Arrow keys or W A S D — pitch and roll
- Shift / Ctrl — throttle up / down
- G — landing gear, F — flaps
- C — chase / cockpit view
- 1 / 2 / 3 — pick a mission on the title screen
- P — pause, M — mute, Space — start / restart
